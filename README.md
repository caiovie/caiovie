## 🧩 Sistemas em Destaque (Projetos Reais)

### ✅ Automação de WhatsApp + Orquestração Multi-Agente
- Agente orquestrador roteia tarefas para subagentes (estoque, agendamento, reservas, cancelamentos, suporte)
- Processamento em fila para lidar com concorrência e mensagens simultâneas
- Dashboards de acompanhamento e analytics de mensagens via Postgres (histórico)

### ✅ Gestão da Loja (Domínio no Supabase)
- Estoque + disponibilidade + agendamentos
- Leitura/escrita transacional no Supabase (PostgreSQL)
- Dashboards operacionais e métricas em tempo real

> Dica: mantenha cada repositório principal como um “case” (Problema → Solução → Arquitetura → Impacto).
